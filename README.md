# Brainstorming & prototyping — yestaki

The **yestaki** design idea: a stacking-style mechanism built around a servo-driven separator with pulley, ball screw, rack (`cremaillere mjarfa`), encoder supports and 20x20 aluminium profile.

## Contents
- `stacking.SLDASM` — assembly
- Ball screw, DC motor, nut system, encoder + supports, smooth stem and servo parts
- `piece util/` — reusable parts

> Note: this repo has the same set of files as [stacking](https://github.com/Eurobot-2026-CAD-departement/brainstorming-prototyping-ideas-stacking).
